# Terminal-Simulator
A custom command-line interface simulator built in C++ to model an operating system terminal. 
## 💻 Project Overview
This repository houses versions of a C++ application meant to model an operating system terminal.
## ⚙️ Core Concepts & Tech Stack
- Programming Language: C++
  - Conditional Loop Logic: Usage of for loops, while loops, etc to create lists and more.
  - Functions: Architecture of parameters and calling functions to compute specific tasks.
  - Memory Management: Usage of input values and variable tracking.
## 🤖 Current Features
- Commands: Utilizes input values for certain unique commands.
- Examples:
  - "help": Displays all commands and syntax references.
  - "terminate": Terminates terminal.
